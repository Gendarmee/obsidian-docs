API Gateway - важнейший архитектурный паттерн для построения сложных, устойчивых и расширяемых систем. Паттерн предлагает создание единого шлюза для общения клиента с нашей системой, что решает целый ряд проблем. Можно представить, что Api Gateway будет той самой границей, которую пересекая пользователь попадает в наше приложение. Так же стоит отметить, что в каком-то смысле является реализацией паттерна [[Фасад]].

Зачастую нашему клиенту нужно обращаться к большому количеству сервисов, к примеру при покупке ему нужны данные о продукте, о наличии товара на складе, стоимости, сроках доставки и т.п.
