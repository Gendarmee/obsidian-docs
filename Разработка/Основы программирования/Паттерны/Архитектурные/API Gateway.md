Паттерн представляет собой создание единой точки входа(шлюза) в наше приложение. Оно по сути будет границей между пользователем, и нашей backend системой. Является некоторой реализацией паттерна [[Фасад]]. Этот паттерн использует для решения проблем, связанный с компоновкой сервисов, их расположение мы скроем за фасадом нашего шлюза, ведь пользователю вовсе не нужно знать количество сервисов их api, порты и т.д.
